# Proyecto_Buñueleria
Crear un sistema informatico que le permita a la Buñueleria El Buen Sabor gestionar de manera digital y organizada la información relacionada con sus ventas, gastos, productos e inventario.

# Objetivos específicos
Realizar el análisis del sistema informático para la gestión de ventas, gastos e inventario de la buñuelería.
Realizar el diseño del sistema informático para el manejo de la información de ventas, gastos, productos e inventario.
Realizar la implementación del sistema informático para sistematizar la información de la buñuelería.
Realizar las pruebas del sistema informático para verificar su correcto funcionamiento.
Realizar la implantación del sistema informático en la buñuelería para facilitar el manejo de la información.
